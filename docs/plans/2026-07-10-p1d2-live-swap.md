# P1d-2 — Live Poll Path over Adapters Implementation Plan


**Goal:** Make the live poll path build and drive `adapter.SnapshotReader`s (via the adapter registry) instead of `driver.Driver`s (via the driver registry) — so `ntcip-asc`/`ntcip-rsu` adapters are the real path, without changing emitted output or the command path.

**Architecture:** `device.Device` holds an `adapter.SnapshotReader` instead of a `driver.Driver`; `device.Manager` builds it from `(Vendor, DeviceKind, Connection)` via `adapter.Registry` (normalizing legacy configs first) and still extracts the SNMP client for the command handler via an optional `SNMPClient()` on the adapter; the scheduler calls `Read()` instead of `Collect()`; `main` wires `ntcip.RegisterTo` and drops the now-dead driver/gnmi registry. All shipped devices are `driver_type: snmp` → the compat shim maps them to `ntcip`, so behavior is preserved.

**Tech Stack:** Go 1.26. Reuses `internal/adapter`, `internal/vendors/ntcip`, `internal/snmp`, `internal/config`.

## Global Constraints

- Module path `github.com/Vikasa2M/openits-collector`. Go 1.26. `go test ./...` resolves `openits-models` via `replace => ../openits-models`.
- **Behavior-preserving on output:** emitted events / subjects / ce-ids for the existing SNMP devices are unchanged (the ntcip adapter wraps the same SNMP driver + translator). The P1a translator/synth goldens and P1b subject golden must stay green.
- **Command path unchanged:** `device.Device.Client` (an `snmp.SNMPClient`) must still be populated so the command handler's SETs work. The ntcip adapter exposes `SNMPClient()` for this (Task 1).
- `gnmi` is an unused stub with zero real devices — its registry wiring is removed. If a config ever sets `driver_type: gnmi` (none do today), it now fails at `Manager.Add` with a clear "no adapter for -" error; that is acceptable and better than a stub that errors only at first poll.
- Each task must leave the tree compiling and `go test ./...` green.
- Commit after each task; `gofmt -s -w .` before committing.

// SNMPClient exposes the wrapped driver's SNMP client so the command handler

```go
// Add builds an Adapter via the registry and registers the device.
func (m *Manager) Add(cfg config.DeviceConfig) error {
	if cfg.ID == "" {
		return &porterrors.DeviceNotFoundError{DeviceID: ""}
	}
	if m.registry == nil {
		return fmt.Errorf("device: manager has no adapter registry")
	}

	// Normalize legacy (driver_type/driver_config) configs into
	// vendor/device_kind/connection so inventory-sourced devices resolve too.
	config.NormalizeDeviceConfig(&cfg)

	a, err := m.registry.Build(cfg.Vendor, cfg.DeviceKind, cfg.ID, cfg.Connection)
	if err != nil {
		return fmt.Errorf("build adapter for %s: %w", cfg.ID, err)
	}
	sr, ok := a.(adapter.SnapshotReader)
	if !ok {
		_ = a.Close()
		return fmt.Errorf("adapter %q for device %s is not a SnapshotReader", a.Descriptor().Key(), cfg.ID)
	}

	d := &Device{
		Config: cfg,
		Adapter: sr,
		Health: Health{Status: pb.DeviceStatus_DEVICE_STATUS_ONLINE},
	}
	if sc, ok := a.(snmpClienter); ok {
		d.Client = sc.SNMPClient()
	}

	m.mu.Lock()
	if existing, ok := m.devices[cfg.ID]; ok {
		_ = existing.Adapter.Close()
	}
	m.devices[cfg.ID] = d
	m.mu.Unlock()

	m.logger.Info("Device added", "device_id", cfg.ID, "adapter", a.Descriptor().Key())
	return nil
}
```

	reg := adapter.NewRegistry()

## Self-Review

**Spec coverage (design §3–5, P1d live path):** Task 1 adds the SNMP-client accessor the command path needs + exports the shim. Task 2 swaps `Device`/`Manager`/scheduler/main to adapters and drops the dead driver/gnmi registry. The command path is preserved (Client still populated). Behavior on output is guarded by the P1a/P1b goldens (unchanged) + the scheduler/manager tests. Deferred by design: `EventProducer` reframing of ATSPM/TrafficVision (P2), `Commander` (P4), the 3 guard-completeness goroutines (tracked separately), moving `driver.Reading`.

**Placeholder scan:** No TODO/placeholder. Task 2 Step 4's one uncertainty (`snmp.NewClient` field names) has an explicit verify-and-fallback instruction (use a local stub if awkward).

**Type consistency:** `device.Device.Adapter` is `adapter.SnapshotReader`; `Manager.registry` is `*adapter.Registry`; `NewManager(*adapter.Registry, ...)`. `Manager.Add` asserts the built `adapter.Adapter` to `adapter.SnapshotReader` and (optionally) `snmpClienter` (`SNMPClient() snmp.SNMPClient`) — the ntcip adapter satisfies both (SnapshotReader from P1c; SNMPClient() from Task 1). Scheduler keeps `sdk/driver` (for `driver.Reading`/`synth`) but calls `dev.Adapter.Read`. `config.NormalizeDeviceConfig` is the Task-1 exported name.
